tdeFlasher v1.0.0

Lightweight, blazing-fast OS image flasher natively designed with TQt3 for Trinity Desktop Environment (TDE) and Linux systems.

Method 1: Add the APT Repository (Recommended)

Add the official repository to your system to receive regular automated updates via apt: 

echo "deb [trusted=yes] https://seb3773.github.io/tdeflasher/ stable main" | sudo tee /etc/apt/sources.list.d/tdeflasher.list
sudo apt update
sudo apt install tdeflasher

Compatible with Q4OS, Debian, Devuan, Ubuntu, Linux Mint and all Debian-based distributions.

Key Capabilities & Architecture

⚡
Iconic 3-Step Wizard
Select Image → Select Drive → Flash! Intuitive, streamlined, and foolproof workflow replicating Etcher without the Electron overhead.
🌐
Flash Directly from URL
Stream and write raw or compressed OS images straight from remote HTTP/HTTPS servers to your USB drive without saving to disk first.
📦
Universal Image Support
Native support for raw .img and .iso, plus on-the-fly streaming decompression for .zip, .xz, .gz, .bz2 via libarchive.
🔒
Safe, Verified & O_DIRECT
High-speed SHA-256 integrity verification, system drive write protection warnings, and unbuffered O_DIRECT I/O to avoid kernel memory exhaustion.
💾
Clone Drive
Direct block-device to block-device replication with real-time speed/ETA metrics and automatic target capacity validation.
🚀
Native TQt3 / C++ Performance
Starts instantly, consumes only a few megabytes of RAM, and seamlessly integrates with Trinity Desktop Environment (TDE).
