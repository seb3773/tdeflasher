Welcome to tdeFlasher Setup

tdeFlasher is a lightweight, blazing-fast OS image flasher natively designed for the Trinity Desktop Environment (TDE).

Key Features:

  • Iconic 3-Step Wizard: Select Image → Select Drive → Flash with zero Electron overhead.
  • Universal Format Support: Flash raw .img / .iso files or compressed archives (.zip, .xz, .gz, .bz2).
  • Flash from URL: Directly write remote OS images over HTTP/HTTPS without prior disk caching.
  • Data Safety & Verification: Automatic SHA-256 integrity verification, Windows installer warnings, and disk safety checks.
  • Native C++/TQt3 Speed: High throughput using O_DIRECT writes and minimal RAM/CPU consumption.
